### Step 3: Insertion Method

**For Word Document (.docx):**
1. Open `01_MANUSCRIPT/OnPoint_Authority_COMPLETE_BOOK.docx`
2. Find diagram placeholder text: `[DIAGRAM: name]`
3. Delete placeholder text
4. Insert > Pictures > Select diagram file from `02_DIAGRAMS/`
5. Resize to fit page width (approx 5.5 inches for 6×9 book)
6. Center image
7. Add caption below: "Figure [ID]: [Name]" in italics
8. Repeat for all 40 diagrams

**For InDesign (Professional Print Layout):**
1. Create new document (6×9, facing pages)
2. Import text from .docx
3. Create master pages with page numbers
4. Place diagrams using Place command (Cmd+D / Ctrl+D)
5. Use SVG files for best quality
6. Set images to 300 DPI for print
7. Apply consistent styling
