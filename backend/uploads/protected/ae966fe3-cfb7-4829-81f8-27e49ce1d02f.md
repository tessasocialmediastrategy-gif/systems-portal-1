# OPS — Sync Tracker (Notion) — Setup (v2026-02-17r3)

## Create Database
Name: **OPS — Sync Tracker**

## Required Properties
- Title (text)
- Canonical ID (text)
- Type (select): BookSection, WebsiteOnly, CopyBlock, Asset, CIMDeliverable
- Source of Truth (select): Book, Notion, Website, CIM
- Website Slug (text)
- Status (select): Planned, Draft, Active, Deprecated
- Owner (person or select)
- Version Lock (text): v2026-02-17r3
- Last Sync Date (date)
- Next Review (date)
- Change Notes (text)
- Links (url)

## Views
- By Status
- Book Chapters (filter Type = BookSection)
- Website Pages (filter Type contains Website)
- Data Room / CIM (filter Type = CIMDeliverable or Canonical ID starts with WP-DR)
- Needs Review (filter Next Review on or before today)

## Template Button (optional)
Create a template: **“New Item (Canonical)”** with prompts:
- Add Canonical ID
- Confirm Source of Truth
- Add links to OneDrive + website
- Set Next Review date
